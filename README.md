# Charla · Artesanos Digitales para negocios

Presentación para dueños y equipos. La estética sale de la landing (`artesanosdigitales.tech`): paleta, greca, isotipos, elementos y el armado del logo.

Abrir `index.html` en el navegador, o servir la carpeta:

```bash
python3 -m http.server 8770
```

Flechas o clic para avanzar. F, pantalla completa.

Los oficios de Hendrik Martina (maestro del telar) y Jesús Lerma (maestro alfarero) son nombres de taller para esta charla, no cargos legales. Las cifras de negocio están en `fuentes.md`. No hay casos medidos ni porcentajes de ahorro propios.
